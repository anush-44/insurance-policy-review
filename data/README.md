# Policy Data

`policies.csv` is the acquisition manifest. `acquire_policies.py` downloads only HTTPS policy wording PDFs from configured official insurer hosts, validates PDF content and product/UIN evidence, records page count and SHA-256, and writes a machine-readable report. Brochures and product marketing pages are not accepted as source PDFs.

Run acquisition and inspect the report:

```powershell
.venv\Scripts\python.exe -m data.acquire_policies
```

The workflow retries transient failures, preserves existing versions unless `--refresh` is passed, rejects invalid PDFs, distinguishes undetected UINs from mismatches, and reports locally present documents whose source provenance is unknown. Downloaded PDFs in `data/raw/` are Git-ignored.

Only rows marked `valid` or `valid_uin_not_detected` are ingested by default:

```powershell
.venv\Scripts\python.exe -m data.ingest_policies
```

For a manually reviewed local file without verified acquisition history, pass `--include-unverified-local` explicitly. Successful ingestion uses the existing parser, chunker, BGE embeddings, Qdrant, and BM25 path and writes a per-policy report under `data/ingestion_reports/`.

`sample_policy.pdf` is generated by `create_sample_pdf.py` for deterministic tests. It is synthetic and is not a real-policy evaluation source. `icici_complete_health.pdf` is a local 63-page wording PDF with selectable text and UIN `ICIHLIP25035V082425`; the file's download provenance has not been matched to the official insurer-hosted bytes.
